# 08-SKILLS

## Qué va aquí

Catálogo de skills/herramientas/workflows que tienes disponibles. Útil para que tu asistente sepa qué puedes hacer y qué no antes de proponerte algo.

Skills aquí son cualquier cosa que puedas ejecutar: comandos slash de Claude Code, scripts propios, herramientas SaaS que dominas, frameworks que conoces.

## Archivos principales

- **`INVENTORY.md`** - lista completa de skills disponibles.
- **`CANDIDATES.md`** - skills candidatos a crearse (lo que repetiste 2 veces y todavía no formalizaste).

## Cuándo agregar algo

- Aprendiste una herramienta nueva y la quieres documentar.
- Hiciste un workflow propio que vas a repetir.
- Notas que un proyecto te enseñó un proceso reusable.

## Cuándo NO agregar acá

- **Conocimiento que no es ejecutable.** Va a `07-KNOWLEDGE/`.
- **Algo que solo aplica a un proyecto.** Va a `06-PROJECTS/<proyecto>/`.

## Ejemplo de entrada en INVENTORY

```
## start-project
- Tipo: slash command de Claude Code
- Ubicación: ~/.claude/commands/start-project.md
- Para qué: arrancar un proyecto con validación previa de duplicados
- Última vez usado: YYYY-MM-DD
```
