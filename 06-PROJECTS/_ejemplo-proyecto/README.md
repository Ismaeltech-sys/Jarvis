# _ejemplo-proyecto

> Esta carpeta es un ejemplo. Bórrala o renómbrala cuando crees tu primer proyecto real.

## Ficha

- **Estado:** activo
- **Inicio:** YYYY-MM-DD
- **Stack:** define el stack (lenguaje, framework, base de datos, hosting)
- **Repo:** ruta o URL del repo donde vive el código (NO en este vault)
- **Audiencia:** quién va a usar esto
- **Resultado esperado:** una frase con el outcome medible

## Contexto

Por qué arrancaste este proyecto. Qué problema resuelve. Cómo descubriste que valía la pena.
