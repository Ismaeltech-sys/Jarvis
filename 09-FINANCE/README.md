# 09-FINANCE

## Qué va aquí

Finanzas por proyecto o por entidad. Útil para entender cuánto cuesta operar cada proyecto y cuánto está generando.

Acá puedes llevar:
- Costos recurrentes por proyecto
- Ingresos por proyecto o canal
- Inversiones puntuales
- Punto de equilibrio estimado

## Cuándo agregar algo

- Un proyecto empieza a tener costos o ingresos rastreables.
- Necesitas decidir si seguir con un proyecto o pausarlo y la decisión depende de la economía.

## Cuándo NO agregar acá

- **Datos contables formales.** Esto no es tu contabilidad, es tu radar.
- **Pagos recurrentes generales.** Esos van a `13-OBLIGACIONES/`.
