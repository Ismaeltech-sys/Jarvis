# 11-IDENTITY

## Qué va aquí

Tu identidad. Cómo te describes, cómo suenas, qué te posiciona. Esta carpeta es la fuente de verdad cuando alguien (o tu asistente) necesita representarte.

## Cuándo agregar algo

- Definiste o cambiaste tu posicionamiento profesional.
- Notaste que tu voz tiene un patrón claro y lo querés dejar escrito.
- Tu rol está evolucionando y necesitás registrar la versión nueva.

## Cuándo NO agregar acá

- **Tu CV completo.** Si necesitás eso, llevalo aparte como PDF.
- **Datos de contacto operativos.** Esos van en notas privadas, no acá.

## Estructura sugerida

```
11-IDENTITY/
├── README.md       ← este archivo
├── identidad.md    ← quién sos hoy
├── voz.md          ← cómo escribís
└── posicionamiento.md  ← qué te diferencia (opcional)
```
