# 04-PUBLISHED

## Qué va aquí

Archivo de lo que ya pusiste afuera. Posts publicados, videos subidos, decisiones tomadas, charlas dadas.

Sirve para dos cosas:
1. **No repetirte.** Antes de escribir algo nuevo, busca acá si ya lo dijiste.
2. **Citarte.** Cuando alguien pregunta "¿qué piensas de X?", encuentras la versión que ya escribiste.

## Cuándo agregar algo

- Publicaste un post → archivas el contenido + URL.
- Grabaste un video → archivas el guion final + link.
- Tomaste una decisión formal (cliente, equipo, producto) → archivas la decisión + contexto.

## Cuándo NO agregar acá

- **Drafts inacabados.** Van a `03-BRIEFS/` hasta que se publiquen.
- **Notas privadas.** Si no se publicó externamente, no es published.

## Ejemplo genérico

`2026-05-15-post-onboarding-quick-win.md`

```
fecha-publicacion: 2026-05-15
canal: blog personal
url: https://miblog.com/onboarding-quick-win

[Contenido del post pegado tal cual fue publicado]

---

Métricas a 7 días:
- Visitas: 1,240
- Tiempo en página: 3:12 promedio
- Comentarios: 8

Aprendizaje: el ejemplo del paso 4 fue el que más resonó
en comentarios.
```

## Convención de naming

`YYYY-MM-DD-<descriptor>.md` - la fecha en el nombre permite ordenar cronológicamente.
